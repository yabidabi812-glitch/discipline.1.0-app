DISCIPLINE 1.1 — русская версия

В архиве:
- index.html — приложение
- manifest.webmanifest — настройки установки как веб-приложения
- sw.js — офлайн-кэш для размещённой версии
- icon.svg — значок
- README.txt — эта инструкция

Как открыть на Android:
1. Распакуй архив на телефоне.
2. Открой index.html в Chrome для проверки.
3. Для установки как отдельного веб-приложения нужна публикация файлов на HTTPS-хостинге.
4. После публикации открой адрес в Chrome → меню ⋮ → «Установить приложение» или «Добавить на главный экран».

Ограничения:
- Это русскоязычное веб-приложение (PWA-заготовка), не APK.
- Настоящий системный виджет Android на рабочем столе в этой версии не реализован.
- Заметки и отметки хранятся локально в браузере. Используй «Скачать копию данных» для резервного сохранения.
- Для публикации можно использовать GitHub Pages или другой статический HTTPS-хостинг.
